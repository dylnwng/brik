Set up the tap+

Brik keeps the state; the key phrase is the brick. Keep the phrase somewhere physically inconvenient — a sticker on the fridge, a card in a drawer, an NFC tag by the door. Laying the brick is free. Lifting it means going to where the phrase lives.

Your key phrase
—
Option A · NFC sticker (no app, ~$1 a tag)
  1. Get NTAG215 stickers. Stick one where you want the ritual to live.
  2. Open NFC Tools → Write → Add a record → Text → paste the payload below.
  3. Hold the top of your iPhone to the tag. iOS reads it without unlocking an app; the phrase appears in the notification. Type it into the command line.
unbrik …
Option B · Shortcuts automation (this is what actually blocks apps)
  1. Shortcuts → Automation → + → NFC → Scan your tag → name it “Brik”.
  2. Add action Set Focus → a custom Focus that allows only what you need. Set it to Toggle.
  3. Add action Copy to Clipboard with your key phrase, so a tap hands you the phrase for Brik's ledger.
  4. Turn Run Immediately on and Notify When Run off.

iOS only lets Focus and Screen Time hide apps — no web page can. So the tag flips Focus for real enforcement, and Brik holds the clock, the streak and the cost.

Option C · Command only

Type brik to lay it, the key phrase to lift it, help for the rest. Works from the phone keyboard, a Shortcut, or anywhere you can type.
